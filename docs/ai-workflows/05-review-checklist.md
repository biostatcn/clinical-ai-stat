# AI 输出审查清单

## 代码审查

- [ ] 统计方法与 SAP 一致
- [ ] 变量名和编码正确
- [ ] 因子/categorical 变量编码正确
- [ ] 参考组设定正确
- [ ] 缺失数据处理适当
- [ ] 假设条件已检验（正态性、方差齐性、PH 假设等）
- [ ] 输出结果可复现
- [ ] 无硬编码路径 / 密钥泄露

## 结果审查

- [ ] 数字准确（sample size, p-value, estimate）
- [ ] 置信区间方向正确
- [ ] 结论表述恰当（不夸大）
- [ ] 敏感性分析与主分析一致
- [ ] Table/Figure 符合公司标准

## 报告审查

- [ ] 统计术语使用准确
- [ ] 符合 ICH E3/E9 指南
- [ ] 方法描述足够详细以复现
- [ ] 无 AI 幻觉（不存在的引用、数据）

## 核查清单模板

```markdown
## 分析核查
- [ ] SAP 规范 ✅ / ❌
- [ ] 分析人群：mITT / PP / Safety
- [ ] 交互效应检查：p = 0.XX
- [ ] 敏感性分析：方向一致 ✅ / ❌
```
