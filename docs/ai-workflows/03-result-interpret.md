# AI 辅助结果解读

## 适用场景

- 模型输出摘要和关键数字提取
- 假设条件诊断的解释
- 敏感性分析结果对比
- 统计术语的通俗化解释

## 典型 Prompt

??? example "解读 MMRM 输出"

    ```
    这是我 MMRM 模型的输出摘要，请帮我：
    1. 以表格形式提取各组 LS mean (SE) 和组间差值
    2. 告诉我治疗效应是否统计学显著 (p < 0.05)
    3. 检查协方差结构选择是否合理
    4. 用通俗语言总结结论
    
    [pasted output]
    ```

## 注意事项

- AI 解读不能替代统计师专业判断
- 监管递交文档中的结论必须由统计师撰写
- 涉及敏感性分析结果的判断需谨慎
