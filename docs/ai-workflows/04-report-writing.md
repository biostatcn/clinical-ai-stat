# AI 辅助报告撰写

## 适用场景

- 统计分析报告 (SAP) 的方法学部分
- 临床研究报告 (CSR) 的统计结果描述
- 发表文章的统计方法段落
- 监管回复的统计解释

## 模板

??? example "方法学段落 Prompt"

    ```
    请帮我撰写 CSR 中统计分析方法的段落：

    研究设计：[简要描述]
    主要终点：[名称和定义]
    分析方法：MMRM
    模型：固定效应含 treatment, visit, treatment*visit, baseline
    协方差结构：非结构化 (UN)
    缺失数据：MMRM 在 MAR 假设下有效
    显著性水平：双边 0.05
    
    风格：正式、学术、符合 ICH E9 指南
    ```

## 原则

1. **不直接复制** — AI 生成的内容必须重新表述
2. **监管合规** — 遵循 ICH E3 (CSR) 和 E9 (统计) 指南
3. **事实准确** — 所有数字必须人工核对
