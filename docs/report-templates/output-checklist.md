# 输出检查清单

## 数据完整性

- [ ] 分析数据集锁定版本已确认
- [ ] 所有受试者数据完整
- [ ] 缺失值已标注且处理方法明确
- [ ] 异常值已核实

## 分析方法

- [ ] 分析方法与 SAP 一致
- [ ] 模型假设条件已满足或记录偏离
- [ ] 协变量定义与 SAP 一致
- [ ] 分析人群定义正确（ITT/mITT/PP/Safety）
- [ ] 交互作用已评估

## 结果一致性

- [ ] 样本量与随机化一致
- [ ] p 值与置信区间方向一致
- [ ] 敏感性分析结果方向一致
- [ ] 结果与之前分析（如有）可复现

## 输出格式

- [ ] Table/Figure 编号正确
- [ ] 标题/脚注完整
- [ ] 缩写已定义
- [ ] 数字精度一致
- [ ] 格式符合递交标准
- [ ] 页码/总页数标注完整

## AI 生成内容专项审核

- [ ] 代码逻辑正确
- [ ] 统计方法适当
- [ ] 无虚构统计量或引用
- [ ] 所有数字可追溯至源数据
