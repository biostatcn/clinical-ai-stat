# 表格/图形规范

## Table 1 格式规范

- 连续变量：均值 ± 标准差（或中位数 [Q1, Q3]）
- 分类变量：n（%）
- 组间比较：p 值（ANOVA / 卡方 / Fisher）
- SMD（Standardized Mean Difference）可选
- 脚注注明统计方法和分析人群

## 统计图形标准

| 规范项 | 标准 |
|--------|------|
| 分辨率 | 300 DPI |
| 字体 | Arial / Times New Roman, 8-10pt |
| 文件格式 | TIFF / PNG / EMF |
| 宽高比 | 4:3 或 5:4 |
| 配色 | 色盲友好配色（ColorBrewer） |
| 图例 | 置于图内或图下方 |

## 递交文件命名规则

```
Draft_<Protocol No.>_<Table/Figure>_<No.>_<Description>_<Date>.rtf
# 示例：
Draft_PROT001_Table_14.3.1_Baseline_Characteristics_20240101.rtf
```
