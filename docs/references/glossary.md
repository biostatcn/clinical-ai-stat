# 术语表

| 术语 | 全称 | 中文 | 简要解释 |
|------|------|------|---------|
| ADaM | Analysis Data Model | 分析数据模型 | CDISC 标准，定义分析数据集结构 |
| ADSL | Subject-Level Analysis Dataset | 受试者水平分析集 | 包含每个受试者一条记录 |
| ADQS | Questionnaire Analysis Dataset | 问卷分析集 | 量表/问卷数据（如 QoL） |
| ADTTE | Time-to-Event Analysis Dataset | 时间-事件分析集 | 生存数据 |
| ANCOVA | Analysis of Covariance | 协方差分析 | 含协变量的方差分析 |
| CSR | Clinical Study Report | 临床研究报告 | 递交的核心报告文档 |
| DSMB | Data Safety Monitoring Board | 数据安全监查委员会 | 独立安全监查 |
| eCRF | Electronic Case Report Form | 电子病例报告表 | 临床数据采集工具 |
| FAS | Full Analysis Set | 全分析集 | 等同于 ITT |
| FDA | Food and Drug Administration | 美国食品药品监督管理局 | — |
| FWER | Family-Wise Error Rate | 族系错误率 | 控制 I 类错误的指标 |
| GEE | Generalized Estimating Equations | 广义估计方程 | 纵向数据分析方法 |
| ICH | International Council for Harmonisation | 国际人用药品技术要求协调理事会 | — |
| ITT | Intention-To-Treat | 意向治疗 | 按随机化分组分析 |
| KM | Kaplan-Meier | Kaplan-Meier 方法 | 生存曲线估计 |
| LOCF | Last Observation Carried Forward | 末次观测值结转 | 缺失数据填补方法（不推荐） |
| LS Mean | Least Squares Mean | 最小二乘均值 | 模型校正后的均值估计 |
| MAR | Missing At Random | 随机缺失 | 缺失数据机制假设 |
| mITT | modified Intention-To-Treat | 修正意向治疗 | 修正后的 ITT |
| MMRM | Mixed Model Repeated Measures | 重复测量混合效应模型 | 临床试验金标准分析方法 |
| MNAR | Missing Not At Random | 非随机缺失 | 缺失数据机制 |
| OS | Overall Survival | 总生存期 | 生存终点 |
| PFS | Progression-Free Survival | 无进展生存期 | 生存终点 |
| PH | Proportional Hazards | 比例风险 | Cox 模型核心假设 |
| PP | Per-Protocol | 符合方案集 | 按实际完成分析 |
| PROM | Patient-Reported Outcome Measure | 患者报告结局 | 患者自评量表 |
| RMST | Restricted Mean Survival Time | 限制平均生存时间 | 非比例风险的替代方法 |
| SAP | Statistical Analysis Plan | 统计分析计划 | 分析的蓝图 |
| SMC | Safety Monitoring Committee | 安全性监查委员会 | 安全监查 |
| SMD | Standardized Mean Difference | 标准化均值差 | 效应量指标 |
| TEAE | Treatment-Emergent Adverse Event | 治疗期不良事件 | 安全性指标 |
| TLF | Tables, Listings, Figures | 表格、列表、图形 | 递交交付物 |
